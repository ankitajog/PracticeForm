# DemoQA Practice Form Automation Testing
## Project Description

This project contains automation testing practice using Java, Selenium WebDriver, TestNG, and Maven. The PracticeFormTest.java class is used to automate test scenarios for the DemoQA Practice Form.
The purpose of this project is to practice web application testing, form validation, handling web elements, and executing test cases using the TestNG framework.

## Technologies Used
- Java
- Selenium WebDriver
- TestNG Framework
- Maven
- Eclipse IDE
- Chrome Browser

## Test Scenarios Covered refer Excel file

- Verify that the Practice Form page loads successfully.
- Verify the Practice Form heading.
- Verify First Name and Last Name fields.
- Verify mandatory field validation.
- Verify alphabetic and invalid characters in name fields.
- Verify valid email format.
- Verify invalid email format.
- Verify blank email field validation.
- Use JavaScriptExecutor to check browser form validation.
- Use TestNG assertions to validate expected results.
